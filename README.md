# Personal Portfolio

This is my personal portfolio website built with **TypeScript**, **React**, and **Tailwind CSS**, deployed on **Vercel**.  
It showcases my skills, projects, and provides an easy way to connect with me.

🌐 **Live Demo:** [portfolio-ts-v2.vercel.app](https://portfolio-ts-v2.vercel.app/)

---

## ✨ Features
- **About Me** – short introduction and background
- **Skills** – technologies and tools I work with
- **Projects** – portfolio of my work with descriptions and links
- **Responsive Design** – optimized for desktop, tablet, and mobile
- **Contact Section** – easy access to email or social links

---

## 🛠 Tech Stack
- **Frontend:** React + TypeScript
- **Styling:** Tailwind CSS
- **Build Tool:** Vite
- **Deployment:** Vercel

---

## 🚀 Getting Started

Clone the repository and install dependencies:

```bash
git clone https://github.com/your-username/your-portfolio.git
cd your-portfolio
npm install
npm run dev
The app will be running at http://localhost:5173
```
